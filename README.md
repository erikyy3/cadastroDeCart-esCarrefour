# cadastroDeCart-esCarrefour
Um repositório feito para o gerenciamento e versionamento do projeto Cartão Carrefour. No nosso sistema será exigido 3 dados mínimos: CPF, Telefon com DDD e um email para contato com o cliente. Ao enviar os dados de forma correta, o sistema buscará se o CPF do cliente consta na base de banco de dados, se for encontrado e não haver uma consulta a menos de 30 dias, o sistema avaliará o score do cliente e se o cliente for aprovado, será concedido um cartão do Grupo Carrefour para o cliente.

Status do projeto: Em desenvolvimento

Tecnologias utilizadas: MySQL e Java
